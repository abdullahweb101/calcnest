Decimal storage formula

Decimal storage measurements use multiples of 1,000. These are commonly used by storage manufacturers and in many data transfer specifications.

Binary storage formula

Binary measurements use multiples of 1,024. They are commonly used in computing and memory-related contexts.

1 KiB = 1,024 bytes
1 MiB = 1,048,576 bytes

Understanding bits, bytes and storage capacity

What is a bit?

A bit is the smallest basic unit of digital information. It can represent one of two values, commonly written as 0 or 1. Computers use combinations of bits to represent numbers, characters, images, sound and other digital information.

What is a byte?

A byte is a group of eight bits. Bytes are commonly used to measure file sizes, memory capacity and storage space. Text files, photographs, videos and software applications are all stored using digital data measured in bytes.

What is a kilobyte and megabyte?

A kilobyte is a decimal storage unit equal to 1,000 bytes. A megabyte equals 1,000,000 bytes. These units are commonly used when describing documents, images, music files and downloaded content.

What is a gigabyte and terabyte?

Gigabytes and terabytes are larger storage measurements. A gigabyte is often used to describe phone storage, memory cards and application sizes. Terabytes are commonly used for computer drives, external hard drives and large backups.

Why are GB and GiB different?

GB is a decimal unit based on 1,000, while GiB is a binary unit based on 1,024. One GB contains exactly 1,000,000,000 bytes, whereas one GiB contains 1,073,741,824 bytes.

This difference can make a storage device appear to have a different capacity depending on how the operating system reports its size. The device may also reserve some space for formatting and system operations.

Data storage units vs data transfer speed

Data storage and internet speed are related concepts, but they measure different things.

  • MB: Megabyte, a quantity of stored data.
  • GB: Gigabyte, a larger quantity of stored data.
  • Mbps: Megabits per second, a data transfer rate.
  • MB/s: Megabytes per second, another way to express a transfer rate.

Because one byte contains eight bits, 8 Mbps is theoretically equal to 1 MB/s before accounting for network overhead and other practical factors.

Megabytes per second = Megabits per second ÷ 8

For example, a theoretical 100 Mbps connection can transfer approximately 12.5 MB of data per second under ideal conditions. Actual download speeds may be lower.

Frequently asked questions

1. How many bytes are in one kilobyte?

One decimal kilobyte (kB) contains 1,000 bytes. One binary kibibyte (KiB) contains 1,024 bytes.

2. What is the difference between GB and GiB?

One GB contains 1,000,000,000 bytes, while one GiB contains 1,073,741,824 bytes. GB uses decimal units and GiB uses binary units.

3. How many bits are in one byte?

One byte contains exactly eight bits.

4. How many megabytes are in one gigabyte?

One decimal gigabyte contains 1,000 megabytes. One binary gibibyte contains 1,024 mebibytes.

5. Why does my hard drive show less storage than advertised?

Manufacturers generally advertise capacity using decimal units. Some operating systems display binary-based values or use different labels. Formatting and system-reserved space can also reduce the capacity available for files.

6. Is a megabit the same as a megabyte?

No. A megabit (Mbit) contains 1,000,000 bits, while a megabyte (MB) contains 1,000,000 bytes or 8,000,000 bits.

7. Does this calculator convert internet speed?

This calculator converts data quantities, not transfer rates. Internet speed is usually measured in units such as Mbps or MB/s.

8. Is 1 TB equal to 1,024 GB?

In the decimal system, 1 TB equals 1,000 GB. In the binary system, 1 TiB equals 1,024 GiB.

9. How do I convert megabytes into gigabytes?

Divide the number of megabytes by 1,000 to get decimal gigabytes. For example, 5,000 MB equals 5 GB.
