Decimal and Binary Storage Units

Digital storage uses two common measurement systems. Decimal units use powers of 1,000, while binary units use powers of 1,024. This distinction explains why advertised drive capacity and some operating system displays may differ.

Decimal unitBytesBinary unitBytes
1 kB1,0001 KiB1,024
1 MB1,000,0001 MiB1,048,576
1 GB1,000,000,0001 GiB1,073,741,824
1 TB1,000,000,000,0001 TiB1,099,511,627,776

Conversion formula

Result = Value × Source factor ÷ Destination factor

This converter uses bits as its base unit. One byte equals exactly 8 bits.

Examples

Frequently Asked Questions

How many bytes are in a kilobyte?

One decimal kilobyte (kB) is 1,000 bytes. One kibibyte (KiB) is 1,024 bytes.

What is the difference between GB and GiB?

One gigabyte (GB) is 1 billion bytes. One gibibyte (GiB) is 1,073,741,824 bytes.

How many megabytes are in one gigabyte?

In the decimal system, one GB equals 1,000 MB. In binary terms, one GiB equals 1,024 MiB.

How many bits are in one byte?

One byte contains exactly 8 bits.

Why does my hard drive show less space than advertised?

Manufacturers generally advertise capacity using decimal units, while some systems display capacity using binary-based calculations or reserve space for system functions and formatting.
